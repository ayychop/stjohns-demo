# stjohns-demo

Single-page marketing site for St. John's Mini Market (Food & Wine), 90 St. Johns Ave, London NW10 4EG.

React + Vite + Tailwind CSS, with Framer Motion and Lenis for the animations.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```

- Shop details (phone, address, map links) and section content live at the top of `src/App.jsx`.
- Colours and shadows are theme tokens in `src/index.css`.
- Photos go in `public/images/` (see the README there for file names).
